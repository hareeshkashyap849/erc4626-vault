Deposit

A deposit is one transaction if the vault already has enough allowance, and two if it does not — the first is the token approval, the second is the deposit. If you reject either one, the page tells you which step stopped.

Redeem

Redeeming returns assets and burns shares. No approval is needed to redeem.
